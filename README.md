# Расширение УТ 11: остаток и закупочная цена в заказе поставщика

Расширение для `1С:Управление торговлей 11`, которое добавляет в форму документа `Заказ поставщику` две колонки в табличную часть `Товары`:

- `Остаток`
- `Закупочная цена`

Исходный код модуля формы лежит в [src/ФормаДокумента_МодульРасширения.bsl](src/ФормаДокумента_МодульРасширения.bsl).

## Что делает код

Код расширения формы:

- программно добавляет два несохраняемых реквизита строк `Объект.Товары`;
- добавляет read-only колонки в табличный элемент `Товары`;
- получает доступный остаток из `РегистрНакопления.ЗапасыИПотребности.Остатки`;
- получает закупочную цену из `РегистрСведений.ЦеныНоменклатуры.СрезПоследних`;
- обновляет значения при открытии формы, после подбора товаров, а также после изменения даты, склада, номенклатуры, характеристики, склада строки и вида цены поставщика.

Колонка `Остаток` показывает доступный остаток: `ВНаличииОстаток - ЗаблокированоВНаличииОстаток - РезервироватьНаСкладеОстаток`. Поэтому товары, зарезервированные заказами клиентов на складе, уменьшают отображаемое количество.

Остаток считается по складу строки `Товары.Склад`; если он не заполнен, используется склад шапки `Объект.Склад`. Если склад не заполнен нигде, показывается суммарный доступный остаток по всем складам.

Закупочная цена берется по виду цены из справочника `ВидыЦен`. Код ищет первый найденный вид цены с одним из наименований:

- `Закупочная`
- `Закупочные`
- `Цена закупки`
- `Закупочная цена`

Если в базе вид цены называется иначе, измените функцию `Расш_Шувалов_ЗПЦО_НайтиЗакупочныйВидЦены`.

## Установка

1. Откройте базу УТ 11 в `Конфигураторе`.
2. Откройте `Конфигурация` -> `Расширения конфигурации`.
3. Создайте расширение, например `Расш_Шувалов_ЗПЦО`.
4. Укажите префикс расширения: `Расш_Шувалов_ЗПЦО`.
5. Заимствуйте в расширение форму:

   `Документы` -> `Заказ поставщику` -> `Формы` -> `ФормаДокумента`

6. Откройте модуль формы расширения и вставьте код из файла [src/ФормаДокумента_МодульРасширения.bsl](src/ФормаДокумента_МодульРасширения.bsl).
7. Сохраните расширение, включите его и обновите конфигурацию базы данных.
8. Откройте заказ поставщику и проверьте, что в табличной части `Товары` появились колонки `Остаток` и `Закупочная цена`.

## Если колонки не добавились автоматически

Код добавляет реквизиты и колонки динамически при создании формы. Если в конкретной версии платформы или формы это заблокировано, добавьте их в расширении формы вручную:

Реквизиты строк табличной части `Объект.Товары`:

- `Расш_Шувалов_ЗПЦО_Остаток`, тип `Число 15.3`
- `Расш_Шувалов_ЗПЦО_ЗакупочнаяЦена`, тип `Число 15.2`

Колонки табличного элемента `Товары`:

- путь к данным `Объект.Товары.Расш_Шувалов_ЗПЦО_Остаток`
- путь к данным `Объект.Товары.Расш_Шувалов_ЗПЦО_ЗакупочнаяЦена`

После ручного добавления оставьте серверную часть кода: она будет заполнять значения.

## Проверка

На тестовой базе проверьте несколько сценариев:

- открыть существующий заказ с товарами;
- добавить товары через кнопку `Подобрать товары`;
- добавить новую номенклатуру в заказ;
- изменить склад в шапке;
- изменить склад в строке товара;
- изменить дату документа;
- проверить товар с характеристикой.

Для расчета доступного остатка используется контур обеспечения УТ 11: регистр `ЗапасыИПотребности` и ресурсы `ВНаличииОстаток`, `ЗаблокированоВНаличииОстаток`, `РезервироватьНаСкладеОстаток`.
